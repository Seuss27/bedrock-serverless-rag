# Security policy

This is a personal lab project, maintained by one person in their spare time. There is
**no SLA** on responses or fixes — please report responsibly and be patient.

## Reporting a vulnerability

Report privately via **GitHub Security Advisories**, not a public issue:

1. Go to the [Security tab](../../security/advisories) of this repository.
2. Click **Report a vulnerability**.
3. Describe the issue, the affected component, and (if known) the impact.

This keeps the report visible only to the maintainer until a fix is ready.

**Do not open a public issue for a vulnerability, and do not paste account identifiers,
role ARNs, bucket names, endpoints, or any other restricted value into a public issue,
comment, or commit** — this repository is public, and those values are free
reconnaissance for an attacker even though none of them are secrets in the credential
sense (see `CLAUDE.md` § *what must not be committed*).
